A faster drop-in for makefun-site 1.0.0: the same static site generator, rebuilt for CPU time. It answers every case exactly as makefun-site does — same output tree, byte for byte — in about a third of the baseline's CPU time on the practice set.

## Run it

```sh
node main.ts
```

Reads `cases.json` from `/input` (or `$MAKEFUN_INPUT_DIR`) and writes `answers.json` to `/output` (or `$MAKEFUN_OUTPUT_DIR`).
